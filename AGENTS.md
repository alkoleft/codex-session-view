# AGENTS.md

Этот файл содержит постоянные правила проекта для агентской работы.

## Правила

### 1. Язык документации

- Вся пояснительная документация проекта пишется по-русски.
- Английский допустим только для имён файлов и каталогов, команд, API, форматов, code identifiers, названий библиотек и устойчивых технических терминов.

### 2. Источник правил

- Новые постоянные правила проекта для агента фиксируются в `AGENTS.md`.
- При изменении договорённостей `AGENTS.md` считается каноническим источником таких правил.

### 3. Документация по событиям

- При любом изменении обработки событий нужно обновлять `docs/log-events.md`.
- К таким изменениям относятся изменения нормализации логов, списка `event_type`, структуры `payload`, маппинга из сырых логов во внутреннюю модель, а также правил дедупликации и объединения событий.

### 4. Завершение работы по OpenSpec change

- По окончании работы над любым OpenSpec change обязательна UAT-проверка с использованием Playwright.
- Все замечания, выявленные на UAT-проверке, должны быть исправлены до завершения работы.
- После каждого исправления замечания UAT-проверка через Playwright выполняется повторно.
- Работа по OpenSpec change считается завершённой только после полного устранения всех замечаний, подтверждённого повторной UAT-проверкой.

### 5. Независимый скролл в UI

- Для экранов с несколькими рабочими областями каждый смысловой блок должен иметь независимый scroll-контейнер.
- Основная область и inspector должны скроллиться независимо и не должны жить на одном общем вертикальном скролле.
- Это правило обязательно для split-view экранов.
